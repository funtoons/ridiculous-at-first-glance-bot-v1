A one-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty: a service that rents out actors to pose as your wildly successful cousin at family dinners, so your relatives finally stop asking when you'll get a real job — $200 a night, smugness included. The pitch is bizarre at first glance (hire a fake cousin?) and sound on second thought (family status pressure is a real market, and the buyer, price, and payoff are all named in the sentence).

## Run it

```sh
python3 main.py
```

It writes the pitch to `/output/entry.txt` (one sentence, 178 characters, deterministic — every run writes the same bytes).
